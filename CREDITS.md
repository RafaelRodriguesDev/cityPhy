# Credits

cityPhy does not copy code from these projects. It installs or uses them, or follows their ideas.

| Project | Author | License | How cityPhy uses it |
|---|---|---|---|
| [graphify](https://github.com/safishamsi/graphify) (`graphifyy` on PyPI) | safishamsi | MIT | **Dependency.** Builds the code graph of each project; `cityphy setup` installs it from PyPI with your permission. Towers are written in graphify's `graph.json` format so graphify can query them too. |
| [claude-mem](https://github.com/thedotmack/claude-mem) | thedotmack | Apache-2.0 | **Inspiration.** The idea of capturing sessions through agent hooks and bringing a short memory back at session start. cityPhy's version keeps everything local and summarizes by rules instead of a model. |
| [Three.js](https://threejs.org) | three.js authors | MIT | Draws the city (npm dependency). |
| [Vite](https://vite.dev) | Vite contributors | MIT | Development server and build (npm dependency). |
| [Vitest](https://vitest.dev) | Vitest contributors | MIT | Tests (npm dependency). |

The example city in `examples/data` is fictional: generated by `scripts/makeExample.ts`.
